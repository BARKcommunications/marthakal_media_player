# Marthakal Media Player

A Raspberry Pi media player that plays YouTube playlists fullscreen on boot, on a
schedule you control. Programming is defined in `playlists.json` (built with the
included visual scheduler) and lives in this repo — **push a change and the Pi
updates itself within ~2 minutes.**

---

## How it works

```
Pi powers on
  → auto-logs in
    → Wi-Fi connects
      → mediaplayer service starts
        → player.py reads playlists.json
          → picks the block scheduled for right now (or the default)
            → plays those items fullscreen, in order, then loops
  ↺ a background timer checks GitHub every 2 min and pulls updates
```

- **Streaming, not downloading** — videos stream from YouTube; nothing is saved to disk.
- **Scheduled** — different content by day of week and time of day.
- **Self-updating** — a systemd timer runs `git pull` and restarts the player when you push.
- **Fullscreen, no desktop** — mpv's DRM output renders straight to the screen (Pi OS Lite).
- **Crash-proof** — systemd restarts the player automatically if it ever stops.

## Building a schedule

Open **`scheduler.html`** in any browser on your computer (just double-click it — it
runs entirely locally, no server needed).

1. **Add schedule blocks** — give each a name, pick the days, set a start and end time,
   and add one or more items. Items play top to bottom, then loop.
2. **Set the default** — what plays when no block matches the current day/time. This is
   the fallback and loops all week in any gaps.
3. Each item is either a **playlist** URL (contains `list=`) or a single **video** URL.
   The tool labels each one so you can tell them apart.
4. The **week preview** on the right shows your programming at a glance, with a live
   "now" line.
5. Click **Export playlists.json**, then commit that file to this repo.

To edit an existing schedule later, click **Import existing** and load your
`playlists.json` back in.

### playlists.json format

```json
{
  "schedule": [
    {
      "name": "Weekday mornings",
      "days": ["mon", "tue", "wed", "thu", "fri"],
      "start": "09:00",
      "end": "12:00",
      "items": [
        "https://www.youtube.com/playlist?list=PLxxxx",
        "https://www.youtube.com/watch?v=singlevideo"
      ]
    }
  ],
  "default": [
    "https://www.youtube.com/playlist?list=PLdefault"
  ]
}
```

Blocks are checked in order — the first one that matches the current day and time wins.
A block whose end time is earlier than its start time (e.g. `22:00`–`02:00`) wraps past
midnight.

## Setup

### Part 1 — On your computer

1. **Install Raspberry Pi Imager** from https://www.raspberrypi.com/software/
2. **Flash the SD card:**
   - Choose **Raspberry Pi OS Lite (64-bit)**
   - Click the **gear icon** (⚙️) and set:
     - **Hostname:** `marthakalmedia001`
     - **Username:** `marthakalmedia001` + a password
     - **Wi-Fi:** your network name and password
     - **Enable SSH:** yes (password authentication)
   - Write the card
3. **Connect the hardware:**
   - Plug HDMI into the display **before powering on** (the Pi needs it connected at boot)
   - Insert the SD card and power on

### Part 2 — On the Pi (via SSH)

1. **Connect** from your computer's terminal:
   ```bash
   ssh marthakalmedia001@marthakalmedia001.local
   ```
2. **Run the one-click installer:**
   ```bash
   curl -sSL https://raw.githubusercontent.com/BARKcommunications/marthakal_media_player/main/setup.sh | bash
   ```

The script installs everything, clones this repo, sets up auto-start and auto-update,
then reboots. Videos play automatically after the reboot.

---

## What the installer does

1. Auto-detects your username (works with any username)
2. Installs `git`, `mpv`, `python3`, `pip`, and video drivers
3. Installs `yt-dlp`
4. Clones this repo to `~/marthakal_media_player`
5. Configures auto-login on boot
6. Creates the `mediaplayer` service (starts on boot, restarts on crash)
7. Creates the `mediaplayer-update` timer (checks GitHub every 2 minutes)
8. Reboots

## Updating content

Just edit your schedule in `scheduler.html`, export, and commit `playlists.json` to
this repo. The Pi pulls the change within ~2 minutes and applies it at the next video.
The same mechanism updates `player.py` itself if you change it — no need to SSH in.

To force an update check immediately (instead of waiting for the timer):
```bash
sudo systemctl start mediaplayer-update
```

## Adding a second Wi-Fi network (optional)

Useful if the Pi moves between locations. SSH in and run:

```bash
sudo nmcli connection add type wifi con-name "Network2" ssid "SECOND_WIFI_NAME"
sudo nmcli connection modify "Network2" wifi-sec.key-mgmt wpa-psk wifi-sec.psk "SECOND_WIFI_PASSWORD"
```

The Pi connects to whichever saved network is available at boot. To prefer one:
```bash
sudo nmcli connection modify "Network2" connection.autoconnect-priority 10
```
Higher number = higher priority.

> Wi-Fi credentials are entered directly on the Pi and never stored in this public repo.

## Managing the player

```bash
sudo journalctl -u mediaplayer -f          # Watch live logs
sudo systemctl restart mediaplayer         # Restart playback
sudo systemctl stop mediaplayer            # Stop playback
sudo systemctl status mediaplayer          # Check status
sudo systemctl start mediaplayer-update    # Force an update check now
```

## Troubleshooting

**Nothing on screen** — make sure HDMI was connected before the Pi powered on; reboot
with it plugged in. Check the service: `sudo systemctl status mediaplayer`.

**"Nothing to play"** — the active block (or default) has no valid items, or the Pi has
no internet. Check `ping youtube.com` and confirm your playlists are public/unlisted.

**A video is skipped** — the player retries a failed video 3 times, then moves on.
Common causes are deleted or region-locked videos. Check the logs.

**yt-dlp errors after a YouTube change** — the auto-updater keeps yt-dlp fresh only if
you bump it; to update manually:
`pip3 install --break-system-packages --upgrade yt-dlp && sudo systemctl restart mediaplayer`.

**An update didn't apply** — updates apply on a 2-minute timer. Force it with
`sudo systemctl start mediaplayer-update`, or check `git -C ~/marthakal_media_player log`.

## Testing on Windows (optional)

`player.py` runs on the Pi only, but you can verify a playlist loads on Windows:

1. Install Python (tick "Add to PATH"), then `pip install yt-dlp`
2. Install mpv from https://mpv.io and add it to PATH
3. Check a playlist expands:
   ```
   yt-dlp --flat-playlist --print url "https://www.youtube.com/playlist?list=YOUR_ID"
   ```
